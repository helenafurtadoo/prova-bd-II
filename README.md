
# Banco de Dados II - 2025

Repositório criado para armazenar os arquivos desenvolvidos durante a disciplina de **Banco de Dados II**.

O projeto reúne a aplicação prática de conceitos estudados em banco de dados, permitindo exercitar a criação, manipulação e consulta de informações por meio de comandos SQL.

## Conteúdos Praticados

Durante a atividade, foram trabalhados conceitos relacionados a:

- Modelagem de banco de dados
- Criação e manipulação de tabelas
- Inserção de dados
- Consultas SQL
- Filtros e condições
- Relacionamento entre tabelas
- Manipulação de registros
- Aplicação prática de conceitos de banco de dados relacionais

## Objetivo

O objetivo deste repositório é registrar a atividade desenvolvida na disciplina de **Banco de Dados II**, aplicando na prática os conhecimentos adquiridos durante as aulas.

Além de servir como registro acadêmico, o projeto também permite revisar conceitos importantes relacionados à organização, armazenamento e consulta de dados.

## Tecnologias

- SQL
- Banco de dados relacional
- Git
- GitHub

## Aprendizados

A atividade contribuiu para reforçar conhecimentos relacionados à construção e manipulação de bancos de dados, principalmente na utilização de comandos SQL para solucionar problemas propostos durante a disciplina.
